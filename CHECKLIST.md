## v0 + пак (2026-10-07)
1. **Пак.** Content Browser → ПКМ по пустому месту → Glaze: Material from Pack → Wood Planks → 2K. Текстуры появились в `/Game/Glaze/Pack/Wood_Planks/2k`, открылось окно Glaze со слотами BC / Normal / ORM (Roughness G, AO R, Metallic B).
2. **Мастер.** При первом создании появляется `/Game/Glaze/M_Glaze`. Шейдер компилируется без ошибок (Output Log: LogGlaze*, ошибки материала).
3. **Live preview.** Поставь на уровень куб/сферу, выдели его, потом открой окно Glaze: материал сразу виден на меше и меняется вживую. Cancel возвращает старый материал, Create при галке «Keep on selected meshes» оставляет новый.
4. **Color Correction.** Desaturation, Contrast, Brightness, Hue Shift, Overlay, Lerp Color + Lerp Amount (0 = исходный цвет, 1 = заданный), Tint.
5. **UV.** Tiling, Rotation — нормаль при повороте должна оставаться правильной (свет падает с той же стороны).
6. **Ремапы.** Roughness/Metallic/Specular/AO: Invert, Contrast, Bias, Min/Max.
7. **Masked + Dithered.** Blend Mode Masked, Opacity Amount, Dithered.
8. **Свои текстуры.** Выдели набор текстур (BaseColor/Normal/ORM или Roughness/AO) → ПКМ → Glaze: Create Material. Несколько наборов сразу → Create & Next / Skip / Create All.
9. **Edit with Glaze.** ПКМ по созданному инстансу → Edit with Glaze → настройки вернулись.
10. **Нойз.** Add → Glaze: Noise from Pack → любой → импортируется в `/Game/Glaze/Pack/Noises`.
11. **Горячие клавиши окна.** Ctrl+Enter — создать, Esc — отмена.

## v2: детали на нойзах (2026-10-08)
12. **Detail Noise.** В окне Glaze, раздел Noise, включи Detail Noise. Без текстуры работает процедурный нойз; с текстурой выбери нойз из пака (Add → Glaze: Noise from Pack). Color / Color Amount и Roughness Amount меняют грязь и блеск по маске.
13. **Пространства.** World: двигай куб, нойз «стоит» в мире. Local: нойз едет вместе с кубом. UV: по развёртке. Pre-Skinned: на анимированном скелетал-меше (Manny) детали не плывут при движении.
14. **Detail Bump.** Detail Bump = 1–2 см: появляется рельеф по нойзу, отрицательное значение — вмятины. Свет должен падать правильно со всех сторон куба.
15. **Macro Variation.** Включи на большой плоскости (пол 20×20 м) с плиткой или травой: повторяемость тайлинга должна заметно пропасть. Macro Size / Macro Amount / Macro Roughness.

## Исправления после ревью Codex (2026-10-09)
16. **Превью не портит уровень.** Открой Glaze с выделенным кубом и нажми Ctrl+S (сохранить уровень). Потом Cancel, перезагрузи уровень: у куба исходный материал. Удаление или копирование куба при открытом окне тоже не должно уносить превью-материал.
17. **Cancel уважает твои правки.** При открытом окне назначь кубу другой материал руками. Cancel его не трогает.
18. **Cancel откатывает настройки текстур.** Возьми Normal с неправильной компрессией (Default). Открой Glaze и нажми Cancel: компрессия вернулась, текстура не помечена изменённой.
19. **Батч.** Два набора текстур в разных папках с одинаковыми именами — это два материала. Folder, изменённый руками, сохраняется для всех наборов. Create All при ошибке остаётся на проблемном наборе.
20. **Edit with Glaze** на чужом (не Glaze) инстансе показывает ошибку, а не перепривязывает его. В режиме Edit поля Name и Folder скрыты. Повторный Edit того же инстанса просто поднимает окно.
21. **Ctrl+Enter** работает, даже когда курсор стоит в текстовом или числовом поле.

## v2: triplanar, параллакс, ветер + второй раунд ревью (2026-10-09)
22. **Triplanar.** UV → Projection = World (Triplanar). Возьми куб без нормальной развёртки или растянутый меш: текстура ложится без растяжений, Texture Size меняет масштаб в см. Свет на нормалях правильный со всех 6 сторон куба и на сфере. Object (Triplanar): двигаешь куб — текстура едет с ним.
23. **Параллакс.** Набор с Height-картой (или ORDp — Height в B) → Parallax Depth 0.02–0.08: кирпичи/плитка «углубляются» при взгляде под углом. При Rotation = 30° сдвиг идёт в правильную сторону (глубина не «плывёт» вбок).
24. **Ветер.** Раздел Wind → Wind. Куст/трава/флаг: By Height — основание стоит, верх качается; Full Sway Height подгони под высоту меша. By Vertex Color — если в меше покрашен красный канал. Direction крутит направление, Gust Size — размер волн порывов.
25. **Detail Noise стал мягче.** Процедурный нойз теперь без «turbulence» и честно в 0..1: пятна грязи могут выглядеть спокойнее, чем раньше — подкрути Detail Contrast. Detail Bump = 0 больше не тратит инструкции.
26. **Opacity Clip / Two Sided** — изменение только этих полей сразу видно в превью (раньше ждало другого переключения). Тащить Opacity Clip — перекомпиляция один раз на отпускании.
27. **Мастер открыт в Material Editor** с несохранёнными правками при обновлении плагина → Cancel в диалоге: Glaze пишет, что надо закрыть редактор, и ничего не ломает.
28. **Undo после Cancel.** Выдели куб с материалом A → открой Glaze → в Details сдвинь куб (Location) → Cancel → Ctrl+Z. Куб вернулся на место и остался с материалом A (раньше возвращался временный превью-материал). Ctrl+Z внутри окна откатывает правки параметров.
29. **Cancel не прячет твои правки текстуры.** Normal с неправильной компрессией → Glaze её исправил → открой текстуру и поменяй, например, Maximum Texture Size, не сохраняй → Cancel в Glaze. Текстура осталась помеченной как несохранённая (звёздочка).
30. **Opacity/Emissive перетаскиванием.** В набор без Opacity перетащи маску в слот Opacity: включается Masked, превью без ошибок сэмплера. В батче следующий набор без Opacity снова Opaque (если Masked включил Glaze, а не ты).
