## v2: детали на нойзах (2026-10-08)
12. **Detail Noise.** В окне Glaze, раздел Noise, включи Detail Noise. Без текстуры работает процедурный нойз; с текстурой выбери нойз из пака (Add → Glaze: Noise from Pack). Color / Color Amount и Roughness Amount меняют грязь и блеск по маске. — ✅ Никита (2026-10-10)
13. **Пространства.** World: двигай куб, нойз «стоит» в мире. Local: нойз едет вместе с кубом. UV: по развёртке. Pre-Skinned: на анимированном скелетал-меше (Manny) детали не плывут при движении. — ✅ Никита (2026-10-10)
14. **Detail Bump.** Detail Bump = 1–2 см: появляется рельеф по нойзу, отрицательное значение — вмятины. Свет должен падать правильно со всех сторон куба. — ✅ Никита (2026-10-10)
15. **Macro Variation.** Включи на большой плоскости (пол 20×20 м) с плиткой или травой: повторяемость тайлинга должна заметно пропасть. Macro Size / Macro Amount / Macro Roughness. — ✅ Никита (2026-10-10)

## Исправления после ревью Codex (2026-10-09)
16. **Превью не портит уровень.** Открой Glaze с выделенным кубом и нажми Ctrl+S (сохранить уровень). Потом Cancel, перезагрузи уровень: у куба исходный материал. Удаление или копирование куба при открытом окне тоже не должно уносить превью-материал. — ✅ Никита (2026-10-10)
17. **Cancel уважает твои правки.** При открытом окне назначь кубу другой материал руками. Cancel его не трогает. — ✅ Никита (2026-10-10)
18. **Cancel откатывает настройки текстур.** Возьми Normal с неправильной компрессией (Default). Открой Glaze и нажми Cancel: компрессия вернулась, текстура не помечена изменённой. — ✅ проверено скриптом через MCP (2026-10-10)
19. **Батч.** Два набора текстур в разных папках с одинаковыми именами — это два материала. Folder, изменённый руками, сохраняется для всех наборов. Create All при ошибке остаётся на проблемном наборе. — ✅ проверено скриптом через MCP (2026-10-10)
20. **Edit with Glaze** на чужом (не Glaze) инстансе показывает ошибку, а не перепривязывает его. В режиме Edit поля Name и Folder скрыты. Повторный Edit того же инстанса просто поднимает окно. — ✅ проверено скриптом через MCP (2026-10-10)
21. **Ctrl+Enter** работает, даже когда курсор стоит в текстовом или числовом поле.

## v2: triplanar, параллакс, ветер + второй раунд ревью (2026-10-09)
22. **Triplanar.** UV → Projection = World (Triplanar). Возьми куб без нормальной развёртки или растянутый меш: текстура ложится без растяжений, Texture Size меняет масштаб в см. Свет на нормалях правильный со всех 6 сторон куба и на сфере. Object (Triplanar): двигаешь куб — текстура едет с ним. — ✅ World на растянутом кубе и сфере проверен через MCP; Object-режим посмотри сам
23. **Параллакс.** Набор с Height-картой (или ORDp — Height в B) → Parallax Depth 0.02–0.08: кирпичи/плитка «углубляются» при взгляде под углом. При Rotation = 30° сдвиг идёт в правильную сторону (глубина не «плывёт» вбок).
24. **Ветер.** Раздел Wind → Wind. Куст/трава/флаг: By Height — основание стоит, верх качается; Full Sway Height подгони под высоту меша. By Vertex Color — если в меше покрашен красный канал. Direction крутит направление, Gust Size — размер волн порывов. — ✅ проверено скриптом через MCP (2026-10-10)
25. **Detail Noise стал мягче.** Процедурный нойз теперь без «turbulence» и честно в 0..1: пятна грязи могут выглядеть спокойнее, чем раньше — подкрути Detail Contrast. Detail Bump = 0 больше не тратит инструкции.
26. **Opacity Clip / Two Sided** — изменение только этих полей сразу видно в превью (раньше ждало другого переключения). Тащить Opacity Clip — перекомпиляция один раз на отпускании. — ✅ проверено скриптом через MCP (2026-10-10)
27. **Мастер открыт в Material Editor** с несохранёнными правками при обновлении плагина → Cancel в диалоге: Glaze пишет, что надо закрыть редактор, и ничего не ломает.
28. **Undo после Cancel.** Выдели куб с материалом A → открой Glaze → в Details сдвинь куб (Location) → Cancel → Ctrl+Z. Куб вернулся на место и остался с материалом A (раньше возвращался временный превью-материал). Ctrl+Z внутри окна откатывает правки параметров. — ✅ проверено скриптом через MCP (2026-10-10)
29. **Cancel не прячет твои правки текстуры.** Normal с неправильной компрессией → Glaze её исправил → открой текстуру и поменяй, например, Maximum Texture Size, не сохраняй → Cancel в Glaze. Текстура осталась помеченной как несохранённая (звёздочка). — ✅ проверено скриптом через MCP (2026-10-10)
30. **Opacity/Emissive перетаскиванием.** В набор без Opacity перетащи маску в слот Opacity: включается Masked, превью без ошибок сэмплера. В батче следующий набор без Opacity снова Opaque (если Masked включил Glaze, а не ты). — ✅ проверено скриптом через MCP (2026-10-10)

## Окно нойзов (2026-10-10)

Покрути Invert, Black/White Point, Gamma, Contrast (1 = чёрно-белая маска), Brightness — превью меняется сразу. Preview Tiling 2–4 — нойз повторяется в превью, швов нет. Esc — закрыть. — ✅ через MCP: тайлинг 3×3, sRGB, 512/256, три колонки; посмотри сам, как ощущается
