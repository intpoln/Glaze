## 1. Что такое Glaze
Плагин редактора UE: быстрое создание материалов из набора текстур. Выделил текстуры → ПКМ → «Glaze: Create Material» → окно: текстуры автоматически разложены по слотам (Base Color, Normal, Roughness, AO, ORM…), галочками включаются функции (Color Correction, ремап Roughness/Specular/AO, Dithered Masked, WPO, world/local-space детали на нойзах) → готовый инстанс.
Главное: **скорость создания материала, UX, интуитивность.**
Родственный проект — Kiln (`C:\Users\intpo\Desktop\Kiln`, процедурная геометрия), оттуда перенесены правила работы.

- Субагенты (Agent tool) — только модель **sonnet**; могут писать код. Сборку/запуск редактора держит один главный агент, субагенты правят непересекающиеся файлы.

- После шага обновлять: план (docs/ROADMAP.md), журнал (SESSION_GLAZE.md), `C:\Users\intpo\Desktop\VPS\WORKLOG.md` (строка «Glaze: …»), CHECKLIST.md (что проверить руками).
- **Никогда не закрывать редактор Fablewood58** — рабочий проект Никиты.
- Память/утечки — отдельный пункт любого ревью.
- Нельзя класть копии плагина внутрь папки, которую сканирует тестовый проект (плагин увидится дважды).
