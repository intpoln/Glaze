1. **medium — Undo guard удерживает материалы после исчезновения preview и компонента.**  
   [SGlazeWindow.cpp:116](/C:/Users/intpo/Desktop/Glaze/GlazeLab/Plugins/Glaze/Source/GlazeEditor/Private/SGlazeWindow.cpp:116), очистка — строка 131.

   `GPreviewGuard` живёт до выгрузки модуля. Его `FGCObject` всегда удерживает `Records[].Originals`; записи с недействительными слабыми указателями удаляются только при следующем Undo/Redo. Обычные закрытие окна и GC их не очищают.

   **Воспроизведение:** назначить мешу временный MID с уникальными текстурами → открыть Glaze → Cancel → удалить меш и очистить Undo → выполнить GC без Undo/Redo. Preview и компонент исчезнут, исходный MID и его зависимости останутся через guard.

   **Величина:** одна запись на пару «preview–компонент» за каждое открытие; удерживаемая память зависит от материалов. Уникальная несжатая RGBA8-текстура 2K — **16 МиБ на один буфер**. Проверять через `obj refs`, `obj list`, `memreport -full`; искать referencer `FGlazePreviewGuard`.

   **Исправление:** регулярно удалять записи с исчезнувшим preview или компонентом, например после GC. Сохранять записи закрытого окна, пока preview действительно доступен из Undo.

3. **medium — новый static switch Detail Bump меняется во время перетаскивания слайдера.**  
   [GlazeApply.cpp:334](/C:/Users/intpo/Desktop/Glaze/GlazeLab/Plugins/Glaze/Source/GlazeEditor/Private/GlazeApply.cpp:334), [SGlazeWindow.cpp:577](/C:/Users/intpo/Desktop/Glaze/GlazeLab/Plugins/Glaze/Source/GlazeEditor/Private/SGlazeWindow.cpp:577).

   `UseDetailBump` вычисляется через `DetailBump != 0`. Interactive-защита применяется только к Opacity Clip, поэтому переход между нулём и ненулевым значением запускает полный статический путь прямо во время drag.

   **Воспроизведение:** включить Detail Noise, оставить Bump = 0 → начать тащить Bump → первое ненулевое значение вызывает `UpdateStaticPermutation`, затем `PostEditChange`. Возврат точно к нулю снова меняет пермутацию.

   **Величина:** **одно статическое обновление на каждый переход 0 ↔ ненулевое**, а не на каждый шаг слайдера. В UE этот путь содержит `FlushRenderingCommands`; при отсутствии shader cache запускается компиляция. Измерять паузу Game Thread и ShaderCompile jobs в Insights.

   **Исправление:** откладывать изменение этого static switch до окончания drag, аналогично Opacity Clip; scalar обновлять отдельно.
