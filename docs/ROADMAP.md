## v2 — детали и WPO
- [x] Детали на нойзах: UV / World / Local (Object) / **Pre-Skinned** (скелеталки — детали не «плывут»); текстура из пака (triplanar в 3D) или процедурный 3D-нойз; влияют на цвет и roughness
- [x] Тест Glaze.Compile — реальная компиляция шейдеров всех пермутаций (`Tools/runtests.sh Glaze rhi`)
- [x] Detail Bump (рельеф от нойза через производные, без доп. выборок), Macro Variation (крупные пятна яркости/roughness против повторяемости), triplanar для нойза
- [x] Triplanar для основных текстур: Projection = UV / World / Object; Texture Size в см; нормали — whiteout-бленд по трём плоскостям (UV-тайлинг и поворот в triplanar не действуют). Pre-Skinned для основных текстур не делал: без pre-skinned тангентов нормали на анимации были бы неверными
- [x] WPO-ветер: направление (yaw), сила (см), скорость, размер порывов, маска: весь меш / по высоте от пивота / красный vertex color
- [x] Height → параллакс (Bump Offset с учётом поворота UV), своя карта или канал packed (ORDp); только в UV-проекции
